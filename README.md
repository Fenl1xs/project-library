# 📚 Warehouse Management System

## 📚 О проекте
Консольное приложение для управления складским фондом товаров. Система позволяет отслеживать остатки товаров, управлять ценами, пополнять запасы и фиксировать продажи.

## 📚 Архитектура проекта

```
project-library/
├── include/
│   ├── Product.h      # Класс товара: ID, название, цена, количество
│   └── Warehouse.h    # Класс склада: каталог товаров, поиск, отчёты
├── src/
│   ├── Product.cpp    # Реализация методов товара
│   └── Warehouse.cpp  # Реализация методов склада
├── main.cpp           # Тестирование системы
├── CMakeLists.txt     # Конфигурация сборки
└── README.md          # Документация
```

### Классы

| Класс | Описание |
|-------|----------|
| **Product** | Модель товара с полями: `productId`, `name`, `price`, `quantityInStock`. Методы: пополнение (`restock`), продажа (`sell`), проверка доступности (`isAvailable`), отображение информации (`displayInfo`) |
| **Warehouse** | Управление каталогом товаров через `std::map`. Методы: добавление товара (`addProduct`), поиск по ID (`findProduct`), генерация отчёта (`generateInventoryReport`) |

## 📚 Сборка и запуск

```bash
mkdir build && cd build
cmake ..
cmake --build .
./WareHouseSystem
```

## 📚 Функционал

- ✅ Добавление товаров в каталог
- ✅ Пополнение запасов (restock)
- ✅ Продажа товаров с проверкой наличия (sell)
- ✅ Изменение цены товара
- ✅ Проверка доступности товара
- ✅ Генерация отчёта по инвентарю
